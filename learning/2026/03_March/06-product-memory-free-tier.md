# Memory comes to Claude's free tier

- **Category:** ① Product release
- **Date:** 2026-03-02  ·  **What it affects:** Claude consumer apps — free plan gains cross-conversation memory
- **Sources:** https://www.engadget.com/ai/anthropic-brings-memory-to-claudes-free-plan-220729070.html · https://support.claude.com/en/articles/12138966-release-notes

## In one line
Claude's memory feature dropped its paywall on Mar 2, 2026, so free-tier users now get cross-conversation memory of their name, job, preferences, and ongoing projects.

## What actually changed
Anthropic extended **Chat Memory** — the automatic ~24-hour synthesis that carries context across standalone conversations — to the **free plan**, completing a roughly eight-month staged rollout: memory launched in Aug 2025 (paid only), expanded to all paid tiers (Pro, Max, Team, Enterprise) in Oct 2025, and became free for everyone in Mar 2026. Free users get memory of personal facts and active projects across conversations at no cost. One capability stays paid: **Chat Search** — semantic search across your full conversation history — remains restricted to Pro, Max, Team, and Enterprise. On the same day, Anthropic also made it easier to **import past conversations from a competing chatbot** into Claude, lowering the switching cost.

## Why it matters
Memory is a retention and stickiness mechanism, not just a convenience: an assistant that remembers your context gets more useful the more you use it, and that accumulated context is a switching cost. Putting it on the free tier — plus a one-click import from a rival — is a deliberate acquisition play aimed at pulling free users off competitors and starting the personalization flywheel before they ever pay. Keeping semantic Chat Search paid preserves a clean free-to-paid upgrade lever.

## Your point of view
- This is a growth/moat move dressed as a feature: free memory + easy import = lower acquisition cost and a personal-context lock-in that compounds over time.
- The free/paid line is drawn cleverly — everyone gets "Claude remembers me" (the sticky part), but "search everything I ever said" stays a paid upgrade.
- For product folks: note the pattern — give away the feature that builds accumulated user-specific value, charge for the power-user retrieval on top.

## What to do
If you build consumer AI, study this as a template for memory as an acquisition-and-retention lever and for where to draw the free/paid boundary. As a user, know that free Claude now persists personal context across chats — mind what you share, and use the memory controls to review or clear it.
